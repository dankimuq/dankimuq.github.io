완성 홈페이지 보기 · Google Sites에 붙여 넣을 전체 코드

핵심: Google Sites의 페이지는 하나, 내부 화면은 31개.
출판·활동·뉴스·구성원·연구 자료를 사이트 안의 메뉴로 이동합니다. 모든 화면과 검색이 index.html에 들어 있으므로 이후 수정 시 삽입 코드 한 곳만 바꾸면 됩니다. 구글 드라이브의 파일 교체만으로 사이트가 바뀌지는 않습니다.

1. 기존 사이트 복사본 만들기

Google Sites 편집기의 더보기 메뉴에서 사이트 복사본을 만들어 두세요. 이 패키지에도 기존 31개 페이지의 원본 HTML이 archive/에 보관되어 있습니다. 기존 사이트에 연결된 문서·자료 파일은 계속 유지하세요.

2. Home 한 페이지에 전체 홈페이지 넣기

  1. Google Sites 편집기에서 기존 Home 페이지를 엽니다. 기존 Home 경로를 유지하면 대표 링크를 바꿀 필요가 없습니다.
  2. Home의 기존 콘텐츠 블록을 정리한 뒤 삽입 → 삽입(Embed) → 코드 삽입(Embed code)을 선택합니다.
  3. Google-Sites-Paste-Code.txt를 일반 텍스트로 열어 전체 선택 → 복사하고 코드 입력란에 붙여 넣습니다. macOS에서는 파일을 VS Code 같은 텍스트 편집기로 열거나 TextEdit을 일반 텍스트 모드로 사용합니다. 브라우저에서 index.html을 열면 화면이 보이므로 코드 복사에는 txt 파일을 사용하세요.
  4. 다음 → 삽입을 누르고, 삽입 영역을 페이지 너비에 맞춰 넓힙니다. 높이도 충분히 확보하여 내부 세로 스크롤을 사용할 수 있게 합니다.
  5. 큰 화면으로 삽입하려면 페이지 → + → 전체 페이지 삽입(Full page embed) → 코드 삽입에서 같은 코드를 사용할 수도 있습니다. 새 페이지로 만들면 홈 설정과 페이지 경로를 확인하세요. 기존 Home에 일반 삽입하는 방법이 기존 /home 주소를 유지하기 가장 간단합니다.

3. 미리보기 확인 후 기존 페이지 정리

  1. 미리보기에서 Home, About, People, Research, Publications, News, Join us 메뉴를 눌러 확인합니다. 검색, 모바일 메뉴, 긴 출판 목록, 연구 하위 자료도 확인합니다.
  2. Google Sites의 기존 개별 페이지는 우선 메뉴에서 숨기면 새 메뉴와 겹치지 않습니다. 화면이 잘 작동하는 것을 확인하고 복사본이 있으면 Home만 남기는 구성을 적용할 수 있습니다.
  3. 게시(Publish)를 누릅니다. 수정한 원본 사이트의 게시 주소를 확인합니다.
기존 /dan, /services, /publications 등의 페이지를 삭제하면 그 옛 주소는 새 삽입 화면으로 자동 연결되지 않습니다. 방문자가 옛 링크를 계속 쓸 수 있어야 한다면 해당 페이지를 메뉴에서 숨긴 채 유지하세요. 한 페이지 삽입 내부의 화면 주소·검색은 Google Sites의 개별 페이지 주소·기본 검색과 별개입니다.

다음번 업데이트

수정된 Google-Sites-Paste-Code.txt의 전체 코드를 기존 Home의 삽입 코드에 교체하고 다시 게시하면 됩니다. 각 연구 하위 페이지를 따로 수정할 필요가 없습니다. ZIP의 편집용 JSON·원본 텍스트는 작업 자료이며, 그것만 바꿔서 업로드해도 삽입된 HTML이 자동 재생성되지는 않습니다.

보존 및 확인 사항

기존 31개 페이지의 내용과 201개 링크를 보존했습니다. 사용자가 제공한 새 편집위원 시작 연도와 지표는 이전 값을 교체했습니다. 과거 원문은 archive/에 남아 있습니다.

GSM 소개·AI-IDS·MTD 소개의 도표 3개는 원본 Google 이미지 주소를 유지했지만 다운로드가 제한되어 이미지 파일이 패키지에 포함되어 있지 않습니다. 표시되지 않는 도표는 원본 파일을 별도로 삽입해야 합니다.

전체 출판 항목, 내부 목적지, 출처 링크 보존, 검색 데이터 및 JavaScript 문법을 확인했습니다. Google Sites의 실제 삽입·게시 환경과 모바일 화면은 최종 미리보기에서 확인해야 합니다. 이 파일들은 준비된 결과이며 현재 Google Sites를 직접 수정하거나 게시한 것은 아닙니다.
